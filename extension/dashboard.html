Cloud sync

Sign in with the same email on every computer and your finished sessions and projects are shared between them, so time from your work laptop counts here too. Your data is stored in your own free Supabase project. Settings and blocklists are not synced; each computer keeps its own.

1. Connect your Supabase project

Create a free project at supabase.com, run sync/supabase-setup.sql in its SQL Editor, then copy two values from Project Settings → API. Step by step in the README.

Recommended Brave settings

An extension can't change these. Do them once:

  • Settings → New Tab Page: turn off Show Brave News and the sponsored images.
  • Settings → Brave Rewards: turn off ad notifications (or Rewards altogether).
  • Settings → Privacy and security → Site and Shield Settings → Notifications: set to Don't allow sites to send notifications.
  • Settings → Appearance: hide the sidebar, Brave Wallet, and Brave Talk buttons.
  • brave://extensions → Focus Up → Details: turn on Allow access to file URLs if you use a local PDF in the Work tab.
